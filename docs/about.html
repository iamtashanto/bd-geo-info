About bd-geo-info

The most comprehensive, high-performance, and open-source geographic database for Bangladesh built for the modern JavaScript & TypeScript ecosystem.

🎯 Our Mission

Building applications in Bangladesh often requires handling address fields—divisions, districts, upazilas, city corporation thanas, unions, and postal codes. Previously, developers struggled with incomplete JSON snippets, outdated postal lists, missing metropolitan police stations, or heavy UI libraries that forced unnecessary dependencies into backend and mobile codebases.

bd-geo-info was created to solve this once and for all: providing an authoritative, zero-dependency, bilingual (English and বাংলা), and fully TypeScript-typed geographic dataset that runs seamlessly in any environment—Node.js, React, Next.js, Vue, Nuxt, Angular, NestJS, Bun, Deno, React Native, and beyond.

Why Developers Choose bd-geo-info

⚡ Framework Agnostic & Lightweight

Zero required runtime dependencies. React UI components are isolated into an opt-in subpath (bd-geo-info/react) so non-React projects never pull in unnecessary dependencies.

🚀 O(1) Hash Map Performance

Datasets are pre-indexed by parent administrative ID. Queries take less than 1 millisecond without scanning through tens of thousands of records.

🏙️ Metropolitan Thana Support

Full support for metropolitan city corporation police stations—such as Dhaka (Mirpur, Gulshan, Dhanmondi, Uttara), Chittagong, Khulna, Rajshahi, and Gazipur.

🔒 Cryptographic npm Provenance

Built and published directly from GitHub Actions with OpenID Connect (OIDC) Sigstore provenance attestation for supply-chain security.
