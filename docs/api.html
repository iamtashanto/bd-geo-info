API Documentation

Comprehensive reference for all methods, data shapes, and TypeScript definitions in bd-geo-info.

getDivisions(language?: 'en' | 'bn')

Async

Returns all 8 administrative divisions of Bangladesh formatted for dropdowns or lists.

import { getDivisions } from 'bd-geo-info';

const divisions = await getDivisions('en');
// Output: [{ value: '1', label: 'Barisal' }, { value: '2', label: 'Chattagram' }, ...]

getDistricts(divisionId: string, language?: 'en' | 'bn')

Async

Returns all 64 districts or filters districts under a specific division ID.

import { getDistricts } from 'bd-geo-info';

const districtsInDhaka = await getDistricts('3', 'en');
// Output: [{ value: '47', label: 'Dhaka' }, { value: '41', label: 'Gazipur' }, ...]

getUpazilas(districtId: string, language?: 'en' | 'bn')

Async

Returns all 610 upazilas & metropolitan thanas under a specific district ID.

import { getUpazilas } from 'bd-geo-info';

const thanas = await getUpazilas('47', 'en');
// Returns 55 upazilas/thanas including Mirpur, Gulshan, Dhanmondi, Savar, etc.

getUnions(upazilaId: string, language?: 'en' | 'bn')

Async

Dynamically loads union data for rural upazilas (4,540 unions total). Returns empty array for metropolitan thanas.

import { getUnions } from 'bd-geo-info';

const unions = await getUnions('365', 'en'); // Savar Upazila
// Output: [{ value: '3272', label: 'Birulia' }, ...]
