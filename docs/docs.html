Integration & Usage Guide

Step-by-step instructions for installing and consuming bd-geo-info in any modern JavaScript or TypeScript environment.

📦 Package Installation

Use your preferred package manager to add bd-geo-info to your project dependencies:

# npm
npm install bd-geo-info
# bun
bun add bd-geo-info
# pnpm
pnpm add bd-geo-info
# yarn
yarn add bd-geo-info

▲ Next.js (Server & Client Components)

Because bd-geo-info functions are pure and async, you can use them inside Server Actions, Route Handlers, or Client Components without any webpack/turbopack issues.

// app/api/locations/route.ts
import { NextResponse } from 'next/server';
import { getDivisions, getDistricts } from 'bd-geo-info';

export async function GET(request: Request) {
  const divisions = await getDivisions('en');
  const dhakaDistricts = await getDistricts('3', 'en');
  return NextResponse.json({ divisions, dhakaDistricts });
}

🟢 Node.js & Express (CJS or ESM)

Works out of the box in both CommonJS (require) and ES Modules (import).

const express = require('express');
const { getUpazilas, getPostCode } = require('bd-geo-info');
const app = express();

app.get('/api/thanas', async (req, res) => {
  const districtId = req.query.districtId || '47';
  const thanas = await getUpazilas(districtId, 'bn');
  res.json(thanas);
});

🦁 NestJS Service Integration

import { Injectable } from '@nestjs/common';
import { getDistricts, getUpazilas } from 'bd-geo-info';

@Injectable()
export class GeoService {
  async getThanasByDistrict(districtId: string) {
    return await getUpazilas(districtId, 'en');
  }
}

⚡ Bun & Deno

Full native support with zero polyfills or build steps required.

// In Deno or Bun
import { getDivisions, getPostCodes } from 'npm:bd-geo-info';

const codes = await getPostCodes('47', 'Mirpur');
console.log(codes);
