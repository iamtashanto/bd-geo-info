Privacy Policy

Effective Date: October 31, 2026

1. Zero Data Collection & Telemetry

The bd-geo-info npm package and library are completely static and offline-first. When you install or run bd-geo-info in your application (browser, server, mobile app, or CLI), it does not collect, transmit, store, or analyze any telemetry, analytics, or personal user information.

2. No External Network Requests

All administrative datasets (divisions, districts, upazilas, unions, postal codes) are bundled locally within your build distribution. bd-geo-info does not make any outbound HTTP/HTTPS requests or connect to third-party tracking APIs.

3. Documentation Site Privacy

This documentation website is hosted on GitHub Pages. Standard server access logs (such as IP addresses and browser user-agent headers) may be processed by GitHub in accordance with GitHub’s own Privacy Statement. We do not use third-party cookies or intrusive tracking pixels on this site.

4. Open Source Transparency

The entire codebase is open-source under the MIT license and publicly auditable on GitHub.
